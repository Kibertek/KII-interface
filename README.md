# KII Interface

Клиентские приложения KII на Flutter для Windows и Android.

## Назначение

Этот репозиторий содержит только пользовательские интерфейсы и клиентские компоненты KII. Серверное ядро, API, бизнес-логика и инфраструктура KII Core разрабатываются отдельно.

## Цели первой версии

- Единый интерфейс Windows и Android.
- Минималистичный тёмный дизайн: графитовый фон, белый текст, оранжевый акцент.
- KII Presence: абстрактное геометрическое ядро и состояния анимации.
- Компактный клиент с низким потреблением ресурсов.
- Поддержка LAN/WAN-подключения и автономного состояния клиента.
- Локальный кэш ресурсов голоса и анимации.
- Фоновые уведомления с визуальным появлением KII и озвучкой, если это разрешено режимом устройства.
- Плавающий режим там, где его поддерживает ОС.

## Структура

- `apps/kii_app/` — основное Flutter-приложение.
- `packages/` — переиспользуемые клиентские модули.
- `assets/` — локальные ресурсы Presence, голоса и звуков.
- `docs/` — архитектура и UX-спецификации.

## Начало работы

Требуется Flutter SDK со включёнными Android и Windows toolchains.

После создания платформенных каталогов командами Flutter:

```bash
cd apps/kii_app
flutter pub get
flutter run -d windows
```

Для Android используйте доступное Android-устройство или эмулятор.

## Принципы

1. Один KII и единая визуальная идентичность на всех устройствах.
2. Сервер хранит мастер-версии ресурсов; клиенты используют локальный кэш.
3. Основной интерфейс не должен быть необходим для работы фоновых уведомлений.
4. LAN и WAN — равноправные пути подключения; клиент должен уметь переживать потерю сети.
5. Тяжёлые модели не загружаются без необходимости.
6. Платформенные функции реализуются через небольшие нативные адаптеры, когда Flutter сам по себе их не предоставляет.

## Статус

Начальная структура проекта. Подключение к KII Core и реализация системных фоновых функций ещё не добавлены.
