# Shared client modules

Planned reusable modules:

- kii_presence — Presence visuals, states and compact mode.
- kii_connection — client-side connection state and route presentation.
- kii_notifications — notification presentation and user preferences.
- kii_voice — voice playback abstraction and resource cache interface.
- kii_design — shared colors, typography and components.

Modules will be extracted into independent Dart packages when their APIs stabilize. Avoid creating empty packages prematurely.
